BIFlow : Automatisation du pipeline BI à travers une architecture multi-agents 1. Le projet Concevoir un système multi-agents capable d’automatiser une grande partie d’un pipeline Business Intelligence, depuis des données brutes jusqu’à un dashboard interactif contenant les KPI et les principaux insights métier. Principe : Données brutes → Compréhension → Nettoyage → Transformation → KPI → Analyse → Dashboard → Explications 2. Le défi À partir d’un ou plusieurs datasets, votre système doit être capable de :  comprendre automatiquement la structure et la qualité des données  identifier et traiter les problèmes de données  préparer les données pour l’analyse BI  identifier et calculer les KPI pertinents pour le métier choisi  analyser les résultats et produire des insights  générer automatiquement un dashboard  expliquer les principales décisions et résultats. Agent Mission Exemple d’actions BI Orchestrator Agent Coordonner le pipeline Planifier les étapes, appeler les agents, gérer les erreurs et valider les résultats. Data Profiler Agent Comprendre les données Détecter types, statistiques, valeurs manquantes, doublons, anomalies et relations. Data Quality / ETL Agent Préparer les données Nettoyer, transformer, joindre les tables et construire un modèle exploitable. KPI & Semantic Agent Construire l’intelligence BI Identifier les dimensions/mesures, définir les KPI et leurs formules. BI Analyst Agent Analyser les résultats Détecter tendances/anomalies et générer des insights et recommandations. Dashboard Generator Agent Créer le dashboard Choisir les visualisations, filtres, KPI et organiser le dashboard. BI Auditor / XAI Agent Contrôler et expliquer Vérifier les résultats, assurer la traçabilité et expliquer les décisions. 4. Fonctionnement attendu Le BI Orchestrator reçoit un objectif métier et organise le travail. Le Data Profiler analyse les données brutes. Le Data Quality / ETL Agent prépare les données. Le KPI & Semantic Agent définit les indicateurs pertinents. Le BI Analyst interprète les résultats. Le Dashboard Generator construit automatiquement le dashboard. Le BI Auditor / XAI vérifie et explique le résultat final. 5. Architecture globale RAW DATA => DATA PROFILING => DATA QUALITY + ETL => KPI / SEMANTIC LAYER => BI ANALYSIS => AUTO-DASHBOARD => AUDIT + XAI RESULTAT : DASHBOARD BI + KPI + INSIGHTS + EXPLICATIONS 6. Choix du domaine Choisissez au moins un domaine métier : e-commerce / retail, télécommunications, banque / finance, transport, tourisme, santé, services publics, énergie, marketing… Exemples de KPI : CA, marge, croissance, taux de churn, panier moyen, satisfaction, temps moyen, taux de résolution, volume de demandes, performance par région/produit… 7. Sources de données Vous pouvez utiliser des datasets publics réels, des APIs ou plusieurs sources à intégrer. Quelques exemples :  Olist Brazilian E-Commerce — commandes, clients, produits, paiements, livraison.  UCI Online Retail — transactions, produits, quantités, prix et clients.  Microsoft AdventureWorks / AdventureWorksDW — ventes et modèle Data Warehouse.  Telco Customer Churn — abonnements, services, facturation et churn.  UCI Bank Marketing — campagnes marketing bancaires.  NYC Taxi Trip Record Data — trajets, horaires, zones et revenus.  NYC 311 Service Requests — demandes de services publics et suivi opérationnel. 8. Technologies possibles Agents / LLM : LangGraph, LangChain, LlamaIndex, CrewAI, AutoGen. Data : Python, Pandas, Polars, SQL, PostgreSQL, Spark, dbt. BI : Power BI, Tableau, Streamlit, Plotly, Dash, Superset. Infrastructure : Docker, REST APIs, Git. 9. Travail demandé  Concevoir l’architecture multi-agents.  Implémenter les agents et leurs outils.  Choisir un ou plusieurs domaines métier et une ou plusieurs sources de données.  Construire le pipeline automatisé de bout en bout.  Générer les KPI et le dashboard.  Mettre en place une couche d’audit et d’explicabilité.  Évaluer chaque agent et comparer les résultats à une approche de référence lorsque cela est pertinent. 10. Livrables attendus  Code source et architecture du système.  Pipeline BI automatisé.  Dataset(s) et documentation des sources.  Data Quality Report.  Catalogue des KPI et formules.  Dashboard BI interactif.  Rapport d’insights et recommandations.  Rapport d’évaluation et XAI.  Démonstration du fonctionnement multi-agents
